# Jumpy Shooty playtest build (Windows)

1. Download **JumpyShooty-windows.zip** (click it, then the download button) and unzip it.
2. Run `JumpyShooty.exe`. If Windows says it doesn't recognise the app, click **More info → Run anyway**.
3. **Host:** Multiplayer → Create lobby (click Allow if Windows asks about network access), then **Copy address** and send it to friends.
4. **Friends:** Multiplayer → type the address into Join lobby.

**New in this build:** Deathmatch mode with weapon pickups, two weapon slots and a pause-menu Loadout. Also recent: 15 new weapons and a Gun Game mode, resolution, frame rate and display settings, synced music, a kick on F, grapple plus flying kick, rocket boots on E and lobbies of up to 16 players.
